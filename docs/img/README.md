# Capturas reais necessárias

As imagens ainda não foram geradas. Capture somente a área da aplicação em uma instalação descartável com dados fictícios, depois da homologação manual. Não inclua barra de favoritos, abas pessoais, DevTools, cookies, senhas, e-mails reais ou dados do cliente. Use nomes fictícios também para as contas exibidas na interface.

| Arquivo | Tela e perfil | Evidência desejada |

Salve PNG nesta pasta com os nomes acima. Revise cada imagem antes de adicionar ao Git. Não há placeholders apresentados como capturas nem imagens artificiais. A ausência de valores em uma imagem não comprova segurança: confira também as respostas da API conforme o checklist.
